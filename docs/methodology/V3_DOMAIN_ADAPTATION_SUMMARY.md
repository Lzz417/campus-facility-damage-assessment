## 1. 实验问题

V2 的严格留出评价（[V2_EVALUATION_SUMMARY.md](V2_EVALUATION_SUMMARY.md)）暴露了跨场景泛化不足，
且定位**检测器为主要瓶颈**。V3 研究的问题是：

> **在保持原训练数据的基础上，引入一个新的公开数据来源并做受控适配，能否改善该来源上的检测性能？**

## 2. 数据：第二来源与治理

| 项 | 值 |
|---|---|
| 来源 | Smart Campus Dataset（Roboflow Universe，version 9；License 标称 CC BY 4.0） |
| 原始规模 | **4,323 张 / 6,602 bbox / 5 类** |
| 完整性 | 缺标注、越界框、字节级重复均为 **0** |
| **污染审计发现** | 部分类别含**屏幕截图、涂层实验室试片、AI 生成图、带第三方水印的图库素材** |
| 来源说明限制 | 页面只标注 "Provided by a Roboflow user"，**无采集地点/方法说明** |

**清洗与映射**：只保留可映射到本项目三类的样本——
`paint_degradation → peeling`、`cracks → crack`、`corrosion → rust`。
`corrosion` 污染最重，剔除约 **57%**。最终映射池 **2,194 张**（剔除 365 + 排除仅含未映射类的 1,764）。

**本仓库不重新分发该来源的任何原始图片**（原因见 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)）。

## 3. 划分：约束组 + 冻结

原数据集的官方划分被**弃用**——审计确认其存在同源近重复跨 split 的泄漏。

自建划分的约束关系（union-find）：

| 关系 | 判据 | 命中 |
|---|---|---|
| exact | SHA256 相同 | **0 组** |
| hash 近重复 | `min(dHash, pHash) ≤ 2` | 539 对 |
| **镜像同源** | 水平翻转后 `min(dHash, pHash) ≤ 2` | 131 对 |
| 保守同视角 | `2 < min ≤ 6` 且尺寸相同 | 718 对 |

结果：**1,984 组**（单张组占 96.5%），**最大组 52 张 = 池的 2.37%**；
划分为 **train 1,536 / val 329 / test 329**（70/15/15）。
**跨 split 泄漏检查：exact / 近重复 / 镜像 均为 0**（且用**两套独立的哈希实现**分别复核）。

**test 在训练前即被 SEALED**，不参与训练、早停、模型选择或阈值选择。

## 4. 训练

- 表述：**continued domain-adaptation / fine-tuning from V2**（初始化权重为 V2 的 detector）。
- 训练数据：MBDD 原训练集 **7,752** + 新来源 train **1,536** = **9,288**（只用原图，**不用**离线增强集）。
- 超参与 V2 对齐（`optimizer=auto`、`imgsz 640`、`batch 32`、`seed 0`、`deterministic`），**epochs 30**，`save_period=1`。
- **未加入**：任何 val/test 数据、V2 的六倍增强集、HU 数据。

## 5. 模型选择（预登记）

候选 = 30 个 epoch checkpoint（`best.pt`/`last.pt` 只作 alias 一致性核对，**不作为候选**）。

- **Forgetting guard**：旧域 MBDD val `mAP50 ≥ 0.0948`（= 基线 0.1185 × 0.80）。
- **Primary**：新来源 val `mAP50` 最大；并列带 ≤0.005 时比 `mAP50-95`，再取更早 epoch。
- 结果：**27/30 通过 guard**，选中 **epoch 27**。

## 6. 最终留出比较（test，n = 329）

两个模型**事先固定**，一次解封、同一 evaluator、同一 test manifest，
primary mAP 参数**逐项相同**（conf 0.001 / NMS IoU 0.7 / max_det 300 / imgsz 640）：

| 指标 | V2 baseline | V3 adapted | **Δ** |
|---|---|---|---|
| **mAP50** | 0.0353 | **0.6533** | **+0.6180** |
| **mAP50-95** | 0.0153 | **0.4283** | **+0.4130** |
| peeling AP50 | 0.0945 | 0.8047 | +0.7102 |
| crack AP50 | 0.0112 | 0.8113 | +0.8001 |
| rust AP50 | 0.0001 | 0.3439 | +0.3438 |

工作点（各自在**同一个 val 上按同一规则**分别校准：V2 conf 0.050 / V3 conf 0.200）：

| 指标 | V2 | V3 |
|---|---|---|
| P / R / **F1** | 0.0964 / 0.1043 / **0.1002** | 0.6984 / 0.7055 / **0.7019** |
| **无预测图比例** | **42.9%** | **4.6%** |

**旧域代价**：MBDD val `mAP50` 由 **0.1185 → 0.1064**，相对 **−10.2%**，
仍在预登记的 20% forgetting guard 之内——**说明新来源适配伴随一定旧域遗忘**。

**本次 test 无任何技术重跑。**

## 7. 讨论（**最重要的解释**）

**V3 并没有推翻 V2，而是进一步说明了问题具有明显的数据域依赖性。**
V2 在严格跨场景评价中表现较弱；而针对某个新来源做训练适配后，**该来源**上的留出性能显著提高。
这说明**当前系统瓶颈更多体现为跨来源泛化，而非完全缺乏损伤识别能力**。

## 8. 必须一起读的边界（不得省略）

1. **同源**：V3 的 train / val / test 来自**同一数据来源的同一次采集**，
   因此结果证明的是**对该来源适配的效果**，**不证明**对未知校园或其它独立来源的泛化。
2. **来源未核实**：该数据集无采集地点/方法说明，**不能**断言其实际采自校园；
   本文件中"校园"一律是对**该数据来源**的简称。
3. **无独立外部来源验证**：本轮没有引入独立的外部测试来源。
4. **只验证 detector**：V3 **没有**重新评价 SAM2 的像素级分割性能；
   分割结论仍来自 V2 的参考集评价，**不随 V3 改变**。
5. **类别映射**由 AI 辅助视觉审计提出、按保守数据治理原则批准，且清洗剔除了大量污染样本。
6. **小样本**：test 仅 329 张、单一来源、单一光照。
7. **研究原型**：本系统不是结构安全评估系统，输出不能用于工程安全性判定。
