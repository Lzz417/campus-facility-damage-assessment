# 演示录屏脚本

> 目标时长 3–5 分钟，展示系统端到端全流程。建议先跑通一遍再录屏。

## 启动

```bash
streamlit run app/app.py
```

## 分镜脚本

### 镜头 1：系统首页（约 20s）
- 展示标题「校园设施损伤智能分割与量化评估系统」。
- 口播：介绍系统定位——面向校园墙面剥落、地面裂缝、设施锈蚀的检测+分割+量化。

### 镜头 2：单张推理（约 60s）
- 侧边栏调置信度（**默认 0.075 = 冻结工作点**），留空标定系数。
  > 若把滑块拖离 0.075，界面会提示「⚠️ 已偏离冻结工作点」，此时**不再是**冻结工作点演示。
- 上传一张含裂缝的测试图（如 `data/splits/images/test/` 下任意图）。
- 展示左右对比：**原图 / 分割叠加**（红=剥落、绿=裂缝、蓝=锈蚀的 BGR 配色说明）。
- 口播：YOLOv11 先定位缺陷框 → ROI 裁剪 → SAM2 框提示分割 → 自适应后处理。

### 镜头 3：量化结果（约 40s）
- 滚动到「量化结果」表格，指出：像素面积、损伤占比、真实面积(mm²)。
- 口播：系统输出可量化的面积与占比，支持标定系数换算真实面积。

### 镜头 4：批量推理 + 报表导出（约 60s）
- 多选上传 3–5 张不同类别缺陷图。
- 展示批量检测报表汇总表。
- 点击「下载 Excel 报表」，打开导出的 `damage_report.xlsx` 展示列结构。
- 口播：批量巡检 + 一键导出，支撑设施维护决策。

### 镜头 5：结束（约 10s）
- 口播总结：级联结构、自研增强与后处理、可量化输出三大价值。

## 演示图片建议

从测试集挑选三类缺陷各 1–2 张（`data/splits/images/test/`），优先选缺陷清晰、类别单一的图，便于画面聚焦。

## 关键指标（可字幕/口播引用）

- 检测：YOLOv11n mAP50 0.858（3 类）
- 分割：完整方案 mIoU 0.692、Precision 0.835、F1 0.818
- 消融：级联 vs 无提示 SAM2，mIoU 0.037 → 0.692（18×）
