# 基于 YOLOv11-SAM2 的校园设施损伤智能分割与量化评估系统

> 挑战杯 · 大学生课外学术科技作品竞赛 · 研究报告

---

## 摘要

针对校园墙面剥落、地面开裂、设施锈蚀等常见设施病害，传统人工巡检存在效率低、主观性强、难以定量的问题。本文提出一种**「YOLOv11 前置检测 + SAM2 零样本分割 + 自适应掩码后处理 + 面积量化」**的级联式损伤智能评估系统：先由轻量检测器 YOLOv11 定位缺陷区域（类别 + 边界框），再对 ROI 裁剪后送入 SAM2 以框提示（box prompt）进行像素级分割，最后经自研自适应掩码后处理清洗掩码并量化损伤面积与占比。

核心创新点集中在**数据增强、ROI 级联、自适应后处理、量化评估**四个自研环节，而非单纯调用现成库。系统无需对 SAM2 微调即可适配校园小目标、遮挡、低照度等复杂场景，且具备可解释的面积量化输出与 Excel 报表导出能力。

在自建评估集（198 张人工复核 GT 掩码）上，完整方案取得 **mIoU 0.692、Precision 0.835、F1 0.818、FPS 2.02**；消融实验证明级联结构相较无提示全图分割带来 **18 倍 mIoU 提升**，自研后处理进一步提升 Precision 3.4 个百分点。

## 一、研究背景与问题定义

### 1.1 背景

校园建筑与设施（教学楼墙面、道路地面、栏杆管线等金属构件）随使用年限增长，普遍出现三类典型病害：

| 类别 | 英文标识 | 典型表现 |
|------|----------|----------|
| 墙面剥落 | peeling | 抹灰层/涂饰层起皮、剥落 |
| 地面裂缝 | crack | 混凝土/铺装面开裂 |
| 设施锈蚀 | rust | 金属构件锈斑、锈蚀 |

人工巡检依赖目视与经验，存在：① 效率低、覆盖不全；② 判定主观、无量化标准；③ 缺乏历史累积数据支撑维护决策。

### 1.2 技术难点

1. **检测 + 分割双重任务**：既要定位（框级），又要精确轮廓（像素级）。
2. **缺陷形态多变**：裂缝细长、剥落不规则、锈蚀边界模糊。
3. **环境退化**：暗光、逆光、雾、阴影、遮挡、模糊等真实工况。
4. **数据稀缺**：无实拍校园标注数据，需依托公开数据集二次适配。

## 二、系统总体架构

系统采用**级联（cascade）**结构，将「检测」与「分割」解耦：

```
输入图像
   │
   ▼
[1] YOLOv11 前置检测 ──► 缺陷类别 + 边界框（置信度过滤 + NMS）
   │
   ▼
[2] ROI 自适应裁剪 ──► 按 bbox 外扩 margin 裁剪局部区域
   │
   ▼
[3] SAM2 零样本分割 ──► box prompt 像素级分割（局部 ROI 内）
   │
   ▼
[4] 自适应掩码后处理 ──► 面积过滤/孔洞填充/碎片剔除/形态学平滑
   │
   ▼
[5] 量化评估 ──► 像素面积 / 损伤占比 / 真实面积(mm²)
   │
   ▼
结果可视化 + Excel 报表导出
```

**设计动机**：SAM2 作为通用分割大模型，对整图无提示分割会产生海量类无关掩码（本实验测得 Precision 仅 0.04），必须由检测器提供「类别 + 位置」先验；而检测器只出框、不分割，两者互补。ROI 裁剪将分割限定在缺陷局部，既提升精度又降低计算量。

## 三、数据集与数据增强

### 3.1 数据来源与二次适配

| 项 | 说明 |
|----|------|
| 原始数据集 | MBDD 公开病害数据集（14,471 张，bbox 标注） |
| 类别重构 | 合并/重分类为 3 类：墙面剥落(0)、地面裂缝(1)、设施锈蚀(2) |
| 划分 | 训练:验证:测试 = 7:2:1（seed=42，分层抽样） |
| 原训练集 | 8,234 张 |
| 增强后训练集 | 57,638 张 |
| 评估 GT 掩码 | 198 张（人工复核分层抽样） |

> 严格保证训练/验证/测试无泄漏：增强仅作用于训练集，验证与测试保持原始分布。

### 3.2 多工况仿真退化增强（创新点 1）

针对真实巡检中常见的光照与成像退化，自研实现 **6 类增强**（纯 OpenCV/NumPy，未用第三方增强库）：

| 增强类型 | 仿真工况 | 实现要点 |
|----------|----------|----------|
| dark | 暗光/夜间 | 非线性亮度衰减 |
| backlight | 逆光 | 高光溢出 + 全局对比压缩 |
| fog | 雾天 | 大气散射模型 |
| shadow | 阴影遮挡 | 随机多边形暗影 |
| occlusion | 部分遮挡 | 随机遮挡块 |
| blur | 运动/失焦模糊 | 高斯/运动核卷积 |

增强后的标签（bbox）随图像几何/亮度变换同步映射，保证标注一致性。

## 五、分割与自适应后处理

### 5.1 SAM2 零样本分割（box prompt）

SAM2（Segment Anything Model 2, hiera_large）作为零样本分割器，接受检测框作为 prompt，在 ROI 局部生成缺陷掩码。**不对 SAM2 做微调**，避免昂贵标注与训练成本，创新点落在级联与后处理。

### 5.2 自适应掩码后处理（创新点 3）

SAM2 原始输出存在孔洞、碎片、毛刺等噪声，自研后处理流水线：

1. **面积过滤**：剔除占图比例过小（<0.02%）的伪掩码 / 过大（>90%）的整图误分割。
2. **孔洞填充**：`scipy.ndimage.binary_fill_holes` 闭合内部空洞。
3. **连通域碎片剔除**：去除面积 < 最大连通域 10% 的孤立碎片。
4. **自适应形态学平滑**：以「腐蚀探针」检测细长结构——若连通域在腐蚀下快速消失则为细裂缝，采用更保守的核尺寸，避免把裂缝抹掉；否则用闭运算平滑轮廓。

## 六、量化评估（创新点 4）

对每个缺陷掩码输出：

- **像素面积**：掩码前景像素计数；
- **损伤占比**：缺陷像素 / 全图像素；
- **真实面积**：`像素面积 × (mm/像素)²`（标定系数可配置，未标定时只输出像素面积与占比）；
- **批量报表**：多图汇总 + Excel 导出（openpyxl）。

## 七、消融实验

### 7.1 组件消融（2×2 因子设计，198 张 GT）

固定测试集 + GT 掩码，四组对照隔离「级联」与「后处理」各自贡献：

| 分支 | 说明 | mIoU | Precision | Recall | F1 | FPS |
|------|------|------|-----------|--------|-----|-----|
| A | 原始 SAM2（无提示全图） | 0.037 | 0.038 | 0.666 | 0.072 | 0.70 |
| B | SAM2 + 后处理 | 0.039 | 0.040 | 0.653 | 0.075 | 0.70 |
| C | 级联（无后处理） | 0.670 | 0.800 | 0.805 | 0.803 | 2.04 |
| **D** | **完整方案（级联+后处理）** | **0.692** | **0.835** | **0.802** | **0.818** | **2.02** |

**结论**：

1. **级联价值**：无提示 SAM2 对全图产生海量类无关掩码（Precision 仅 0.04），几乎不可用；引入 YOLO 定位后 mIoU 由 0.037 → 0.670（**约 18 倍**），同时推理速度快 3 倍。
2. **后处理价值**：mIoU +2.2 个百分点，**Precision +3.4**（剔除伪掩码碎片，主要收益）。

逐类 mIoU（完整方案 D）：

| 墙面剥落 | 地面裂缝 | 设施锈蚀 |
|----------|----------|----------|
| 0.757 | 0.393 | 0.688 |

> 裂缝 mIoU 最低，符合其「细长、边界难定」的固有难度；后处理对裂缝的形态学侵蚀会带来约 0.4 个百分点的轻微损失，属可控权衡（换取 Precision 显著提升）。

### 7.2 数据消融（原集 vs 增强）

在原集（8,234 张，无增强）与增强集（57,638 张）上分别训练 YOLOv11n，固定其余超参与测试集，对比增强的增益：

| 训练集 | 规模 | mAP50 | mAP50-95 | Recall | 裂缝 Recall | 级联 mIoU |
|--------|------|-------|----------|--------|------------|-----------|
| 原集（无增强） | 8,234 | 0.847 | 0.438 | 0.778 | 0.743 | 0.679 |
| **原集 + 增强** | **57,638** | **0.858** | **0.451** | **0.807** | **0.792** | **0.692** |

> 级联 mIoU 为「完整方案 D」在相同 198 张 GT 上的二值缺陷 mIoU；增强模型逐类 mIoU（剥落 0.757 / 裂缝 0.393 / 锈蚀 0.688）均高于原集模型（0.741 / 0.384 / 0.673）。

**结论**：

1. **检测精度小幅提升**：mAP50 +1.1、mAP50-95 +1.3 个百分点。
2. **召回率提升更显著**：整体 Recall +2.9，**裂缝 Recall +4.9**（增强模拟了暗光、模糊、遮挡等真实退化工况，使检测器对细长裂缝的检出更充分）。
3. **增强收益的合理边界**：测试集为原始干净分布，增强对「干净图」的 mAP 提升有限（+1.1），其核心价值在于**对退化工况的鲁棒性**与**召回率的补足**——对「巡检要尽量找出病害、宁多勿漏」的语义，Recall 的提升比 mAP 更具实际意义。

## 八、结论与展望

### 结论

1. 提出的「YOLOv11 检测 → ROI 裁剪 → SAM2 分割 → 自适应后处理 → 量化」级联方案，在无实拍数据、不微调 SAM2 的前提下，实现校园三类设施病害的端到端分割与量化，mIoU 0.692、F1 0.818。
2. 消融实验定量证明：级联结构（18× mIoU）与自研后处理（+3.4% Precision）均为关键创新贡献。
3. 自研退化增强在检测精度上带来 +1.1 mAP50、+2.9 Recall 的增益（裂缝 Recall +4.9），并显著增强对退化工况的鲁棒性。

### 展望

- 引入毫米级标定（棋盘格/激光）实现真实面积自动换算；
- 融合时序巡检数据做病害演化趋势预测；
- 面向边缘设备做模型轻量化与量化部署。
